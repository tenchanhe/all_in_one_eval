I am using litellm to run the LLM, and the local model is served via Ollama. The --model parameter should be specified example like this:

```
python3 main.py --model "ollama/llama3.2:8B" --input_file "input.parquet" --score_file "score.csv" --language "eng"
```

Additionally, if the input file is in Parquet format, it needs to follow this structure

```
{"question":"question","subject":"subject","choices":["choice A","choice B","choice C","choice D"],"answer":"choice A"}
```
